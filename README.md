# 🍜 Menumi — Cocina de Autor Asiático-Colombiana

> **Dos cocinas. Una mesa.** El wok se encuentra con el fogón en Bogotá.

Sitio web  para **JOVENES CREATIVOS**, un concepto de cocina de fusión asiático-colombiana enfocado en platos creativos, exploración de sabores y pedidos directos en Bogotá.


---

## ✨ Características principales

- **Landing page editorial:** Presentación del concepto de fusión (*achiote + jengibre*, *plátano + bok choy*) y llamados a la acción para explorar la carta o pedir por WhatsApp.
- **Favoritos de la casa:** Destacados visuales con platos insignia como *Sancocho ramen*, *Patacón bao* y *Arroz chino paisa*.
- **Navegación multipágina:**
  - `/` — Inicio y propuesta gastronómica.
  - `/nosotros` — Historia y filosofía del proyecto.
  - `/menu` — Carta / catálogo de platos.
  - `/contacto` — Canales de contacto y atención.
  - `/admin` — Acceso de administración (`Iniciar sesión`).
- **Pedidos directos por WhatsApp:** Integración rápida para gestionar pedidos a domicilio en Bogotá.
